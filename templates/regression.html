Pipeline Notes

  • Target: continuous {{ target }} (mg/dL) — regression only, never binned into classes.
  • Split: chronological 80/20 so the model never trains on future readings.
  • Preprocessing: leakage-safe ColumnTransformer (StandardScaler + KNN imputer for numeric, most-frequent impute + one-hot for categorical) fitted on train data only.
  • Support Vector Regressor trains on a 3000-row subsample for speed (noted in the comparison table).
  • Best model selection: highest test R² across all successfully trained candidates.
