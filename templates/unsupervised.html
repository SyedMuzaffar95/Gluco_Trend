Model Pipeline

  • Every method runs automatically with fixed parameters when the page opens; there are no parameter inputs.
  • Features: {{ features | join(", ") }}.
  • Missing values: filled with median of each column (K-Means, DBSCAN, projections); rows with missing values dropped where PCA is fitted.
  • K-Means: n_clusters=2, random_state=42, n_init=10.
  • Elbow Method: K-Means inertia for k = 1 to {{ elbow_result.max_clusters if elbow_result.error is none else 10 }}; recommended k via the largest second difference of the inertia curve; elbow_curve.png plotted.
  • K-Means++: n_clusters=3 with init="k-means++", random_state=42, n_init=10; PCA scatter coloured by cluster.
  • MiniBatch K-Means: n_clusters=3, batch_size=1024, random_state=42, n_init=10 for faster clustering on large datasets.
  • Silhouette Analysis: scores K-Means (k=3), Hierarchical (k=3, ward) and DBSCAN (noise points excluded) on StandardScaler features sampled to at most 5000 rows.
  • Hierarchical: sklearn AgglomerativeClustering, n_clusters=3, linkage="ward", StandardScaler applied first, capped at 4000 sampled rows.
  • DBSCAN: eps={{ dbscan_eps }}, min_samples={{ dbscan_min_samples }}. Silhouette score computed only when n_clusters ≥ 2 and non-noise points > n_clusters.
  • PCA: StandardScaler applied first, then PCA with n_components={{ pca_n_components }}; explained and cumulative variance displayed.
  • t-SNE: n_components=2, perplexity=30, random_state=42, run on up to 2000 sampled rows; scatter coloured by K-Means cluster.
  • UMAP: umap-learn, n_components=2, n_neighbors=15, min_dist=0.1, random_state=42, StandardScaler applied first, up to 5000 sampled rows.
  • Isolation Forest: n_estimators=100, contamination=0.05, random_state=42 on the full dataset; 1 → Normal, -1 → Anomaly stored as IsolationForest_Status.
  • One-Class SVM: kernel='rbf', nu=0.05, gamma='scale' with StandardScaler on the full dataset; 1 → Normal, -1 → Anomaly stored as OneClassSVM_Status.
  • Autoencoder: sklearn MLPRegressor (8 - 2 - 8) trained X → X; anomalies are samples above the 95th percentile of reconstruction error.
  • Data Augmentation: rows sampled with replacement, Gaussian noise (5% of column std) on numeric columns clipped to original ranges, random_state=42; original dataset unchanged and nothing written to disk.
  • Plots: K-Means, Hierarchical, DBSCAN, PCA, t-SNE, UMAP scatters and the autoencoder error distribution in static/plots.
