Model Pipeline

  • Single feature: glucose_lag_1 (glucose reading from 15 minutes earlier)
  • Target regression: glucose | Target classification: High if glucose ≥ 140 mg/dL, else Normal
  • Train/test split: chronological 80/20 split
  • Simple Linear Regression: scikit-learn LinearRegression on one feature
  • Logistic Regression: StandardScaler + LogisticRegression pipeline
  • Metrics regression: MAE, MSE, RMSE, R² | Metrics classification: Accuracy, Precision, Recall, F1, Confusion Matrix
